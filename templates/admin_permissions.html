Permission Structure

Roles separate full application administration, company-scoped administration and standard workspace access.

Application Admin Full system control

Can create tenants, manage all companies, amend any user role, configure system settings, broadcasts, audit retention and global account fields.

Application Admin is intended for the small group who administer the full hosted enterprise system.

Company Admin Tenant control

Can manage users, roles, passwords and access inside their own company tenant only.

Company Admins cannot see another company, assign Application Admin access or manage application-level controls.

Manager Workspace user

Can use their own private PipeFlow workspace for accounts, contacts, partners, outreach, tasks, reports and exports.

Team reporting can be added later without changing the privacy model.

User Standard access

Can manage their own PipeFlow activity and data. They cannot administer profiles, change global fields or delete accounts.

Best for everyday sales users.

Inactive Access paused

Cannot sign in. The profile is retained so access can be restored later if needed.

Use this when someone leaves or no longer needs access.

Tenancy rule

Every user must belong to one tenant. Company Admins only see their own company.

Sharing boundary

Sharing and assignment lists only include users inside the same company tenancy.

Global controls

Only Application Admins manage tenants, broadcasts, global account fields and audit retention.
