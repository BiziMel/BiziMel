Permission Structure

Roles are deliberately simple. Admins manage access and configuration, while each user keeps their own PipeFlow data private.

Admin Full control

Can manage profiles, grant or remove admin access, reset passwords, deactivate users, configure account fields and delete accounts in their own workspace.

Admin access does not open another user's private account, contact, partner, outreach or task data.

Manager Workspace user

Can use their own private PipeFlow workspace for accounts, contacts, partners, outreach, tasks, reports and exports.

Team reporting can be added later without changing the privacy model.

User Standard access

Can manage their own PipeFlow activity and data. They cannot administer profiles, change global fields or delete accounts.

Best for everyday sales users.

Inactive Access paused

Cannot sign in. The profile is retained so access can be restored later if needed.

Use this when someone leaves or no longer needs access.

Privacy rule

Admins manage the system, not another user's private PipeFlow records.

Account deletion

Only admins see and can use Delete Account, and only inside their own workspace.

Global fields

Account field changes appear on every user's forms, while field values stay private per user.

User Permissions

Promote trusted users to Admin, move people back to standard access, or pause profiles when access is no longer needed.
